# Product

## Register

product

## Users

The primary user is a Mac owner who wants Mole's full desktop workflow without working in Terminal: cleanup, software management, maintenance, disk analysis, live status, battery and fan tools, and quick everyday controls from the menu bar. They need to understand what will happen before anything changes.

## Product Purpose

Provide a native macOS system utility aligned with the public feature set of Mole's official desktop app. Native monitoring and everyday tools work independently, while the current deep-maintenance workflows reuse the installed Mole CLI until equivalent native services replace them. Success means the user can safely complete the full desktop workflow without typing shell commands.

## Brand Personality

Restrained, clear, reassuring. The product should feel like a careful native macOS utility: direct language, calm feedback, and confidence grounded in visible evidence rather than decoration.

## Anti-references

- Terminal-first interfaces that expose commands, flags, and raw logs as the primary experience.
- Aggressive “one click fixes everything” cleaners that use alarmist warnings or pressure tactics.
- Dense monitoring dashboards full of decorative gauges, oversized metrics, and nested cards.
- Flashy neon utility themes or fake glass surfaces that weaken readability and trust.

## Design Principles

- Show the evidence before asking for action.
- Make safe choices the default and destructive choices deliberate.
- Translate Mole concepts into plain language while keeping details available on demand.
- Keep the primary workflow short, with progress and recovery information always visible.
- Feel at home on macOS and respect system appearance and accessibility settings.

## Accessibility & Inclusion

Support light and dark system appearances, keyboard navigation, VoiceOver labels, scalable text where macOS controls allow it, sufficient contrast, and Reduce Motion. Never communicate cleanup risk or status by color alone.
