# Security policy

Melo can request privileged access to AppleSMC through a deliberately narrow
Helper. Please do not publish suspected vulnerabilities, signing bypasses, or
unsafe hardware behavior in a public issue before they have been assessed.

Report security issues privately through GitHub Security Advisories for this
repository. Include the macOS version, Mac model, Melo version, relevant Doctor
output with personal paths removed, and steps to reproduce.

Supported versions are the latest tagged release and the current `main`
branch. Hardware-write issues should be treated as safety-sensitive even when
automatic recovery appears to work.
